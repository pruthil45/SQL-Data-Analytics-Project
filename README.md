# SQL-Data-Analytics-Project
Developed a comprehensive SQL-based Data Analytics project using real-world business datasets to uncover actionable insights and support data-driven decision-making. The project covers end-to-end analytical workflows, including database exploration, KPI generation, sales and customer analysis, trend identification, performance evaluation, segmentation, cumulative analysis, and reporting. Advanced SQL techniques such as Window Functions, CTEs, Aggregate Functions, Date Functions, and Conditional Logic were utilized to transform raw data into meaningful business intelligence. The project demonstrates strong skills in data analysis, problem-solving, query optimization, and analytical thinking while simulating real-world responsibilities of a Data Analyst.
